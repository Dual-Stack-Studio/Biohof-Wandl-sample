# Biohof Wandl: sample page

Concept mock-up of a one-page website for **Biohof Wandl**, made by [Dual-Stack Studio](https://dualstackstudio.com).
It is **not the official website** of Biohof Wandl and has not been published or approved by them yet.

- Static site: `index.html` + `images/` + `video/` (no build step, no tracking).
- Sample photos come from Wikimedia Commons under CC BY-SA licences; authors and sources are listed in [`CREDITS.md`](CREDITS.md) and in the page footer.
- `video/andrea-ueber-uns.mp4` is a **sample video** made from those photos. The real video replaces the file with the same name.
- Texts in `[square brackets]` are still to be confirmed with the farm.
- The page asks search engines not to index it (`noindex`).

## View it

Open `index.html` in a browser, or use the GitHub Pages link of this repository (Settings, Pages, Deploy from branch `main`, folder `/ (root)`):
https://dual-stack-studio.github.io/Biohof-Wandl-sample/

## Replace the sample content

1. Put the real photos into `images/` (same file names) and update `CREDITS.md`.
2. Save the real video as `video/andrea-ueber-uns.mp4`.
3. Fill in the `[folgt]` placeholders (opening hours, prices, phone, Facebook link).
